# Framework figure

- [overview.png](overview.png): inline display in the repository homepage.
- [overview.pdf](overview.pdf): original vector figure for zooming and reading fine labels.

The PDF is the author-supplied overview matching Fig. 1 of manuscript v2, synchronized on 2026-10-09. The PNG is rendered from that PDF for the repository homepage. Both show CAPR, CPGR and CER.

The figure presents the full algorithmic flow. The released command evaluates a single master at a time. Selector behavior, upstream logical-conductor aggregation, invalid-input handling and CER fallback are specified in [PAPER_MAPPING.md](../PAPER_MAPPING.md).

These are two formats of the same overview, not a collection of experimental figures. They are optional documentation assets; no build, inference or evaluation command reads them. The PDF is provided for legibility when zooming.
